# 🚀 AI-Проекты для учебы и творчества

Добро пожаловать в мой личный проект! Это сборник веб-приложений, созданных с использованием искусственного интеллекта, нейросетей и современных веб-технологий. 

Проект создан для того, чтобы помогать школьникам и учителям делать учебу проще, интереснее и продуктивнее.

## 🌟 Что внутри?

В главном меню собраны 6 уникальных приложений:

1. **🎯 Умный Фокус** — Таймер для учебы со слежкой через камеру. Нейросеть следит за твоим лицом и голосом напоминает вернуться к работе, если ты отвлекся.
2. **📝 AI-Помощник учителя** — Генератор планов уроков. Учитель вводит тему и класс, а нейросеть за 5 секунд пишет подробный план с целями, задачами и ходом урока.
3. **🧠 AI-Обучалка** — Умный репетитор. Умеет объяснять сложные термины «как для 5-летнего», переводить молодежный сленг на взрослый язык или читать строгую лекцию.
4. **⚔️ ИИ-Спорщик** — Чат с нейросетью, которая спорит с тобой на любые темы. Сможешь ли ты переубедить искусственный интеллект?
5. **🎮 Hand Saber** — Игра с управлением жестами. Разрубай летящие кубики руками перед веб-камерой.
6. **    Нейро-Художник** - Рисует картинки по вашему описанию.

## 🛠️ Технологии

Проект написан на чистом JavaScript без использования тяжелых фреймворков. 
*   **Frontend:** HTML5, CSS3, JavaScript (ES6+).
*   **Backend (API):** Deno Deploy (TypeScript).
*   **Нейросети:** Groq API (модель Llama 3), MediaPipe (компьютерное зрение для камеры), Pollinations AI (генерация изображений).
*   **Хостинг:** GitHub Pages.
